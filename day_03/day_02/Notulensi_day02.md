## Day 02 - Percabangan If Else

Hari ini saya belajar tentang percabangan dalam program.

Materi yang dipelajari:
- `if` digunakan untuk menjalankan kode jika kondisi bernilai benar.
- `elif` digunakan untuk mengecek kondisi lain jika kondisi sebelumnya salah.
- `else` digunakan jika semua kondisi sebelumnya salah.
- Operator perbandingan: `>`, `<`, `>=`, `<=`, `==`, dan `!=`.
- Operator logika: `and`, `or`, dan `not`.
- Perbedaan `=` dan `==`.
- Beberapa `if` terpisah bisa membuat output keluar lebih dari satu.
- `if-elif-else` digunakan jika kita hanya ingin satu keputusan akhir.

Hubungan dengan SmartFlow:
- Percabangan digunakan untuk menentukan status kemacetan.
- Percabangan digunakan untuk menentukan rekomendasi sampah.
- Percabangan digunakan untuk menentukan prioritas wilayah.
