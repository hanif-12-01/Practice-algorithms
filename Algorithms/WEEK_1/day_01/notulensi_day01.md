## Notulensi Hari Ini

- Belajar tentang variabel.
  - Variabel adalah tempat untuk menyimpan data di dalam program.

- Belajar perbedaan tipe data `str`, `int`, `float`, dan `bool`.
  - `str` digunakan untuk menyimpan teks atau karakter.
    Contoh: `"Hanif"`, `"Teknik Informatika"`, `"123"`
  - `int` digunakan untuk menyimpan bilangan bulat.
    Contoh: `21`, `85`, `-10`
  - `float` digunakan untuk menyimpan bilangan desimal.
    Contoh: `3.14`, `85.5`, `178.0`
  - `bool` digunakan untuk menyimpan nilai logika benar atau salah.
    Contoh: `True` dan `False`

- Belajar fungsi `input()`.
  - `input()` digunakan untuk menerima atau mengambil data dari user.
  - Secara default, semua data dari `input()` dibaca sebagai string.

- Belajar kenapa input angka perlu dikonversi ke `int`.
  - Karena data dari `input()` awalnya dibaca sebagai string.
  - Jika ingin melakukan operasi matematika, data harus dikonversi menjadi angka menggunakan `int()` atau `float()`.
  - Contoh: input `"3"` tanpa `int()` akan dibaca sebagai teks, bukan angka.

- Belajar fungsi `print()`.
  - `print()` digunakan untuk menampilkan output atau hasil program ke layar.

- Belajar pola `input → proses → output`.
  - Pola ini adalah alur dasar dari sebuah program.
  - `input` berarti data masuk.
  - `proses` berarti data diolah.
  - `output` berarti hasil ditampilkan.
